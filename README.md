# Object Oriented Programming - Lab 1 (Week 6/7)
Erciyes University - Software Engineering Department

## Sınıflar (Classes)
- `MenuItem.java`: Menü öğesi özellikleri, miktar doğrulama ve fiyat hesabı.
- `Address.java`: Müşteri adres bilgileri.
- `Customer.java`: Müşteri modeli (Address sınıfı ile composition ilişkisi).
- `Order.java`: Sipariş sepeti, ürün ekleme/çıkarma, kupon indirimi, checkout ve statik istatistikler.
- `Coupon.java`: İndirim kuponu modeli.
- `InvalidQuantityException.java`: Geçersiz miktar (<= 0) hatası.
- `ItemNotFoundException.java`: Sepette bulunamayan ürün hatası.
- `MinimumOrderException.java`: Minimum sipariş tutarının altındaki sipariş hatası.
- `Main.java`: Tüm isterleri doğrulayan test senaryosu.
